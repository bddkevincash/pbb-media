# pbb-media

Media for **Pit Box B.E.T.S.** (Benchmark Efficiency Tracking System), an independent motorsports analytics project
covering NASCAR, F1 and INDYCAR. This repository hosts the slide images used for Pit Box social posts.

## PBB rclone (Google app)

"PBB rclone" is a private Google Cloud app used only by its owner to copy files between his own Google Drive folder
and his own automated data jobs. It is not offered to anyone else. See the [privacy policy](PRIVACY.md).

Independent fan analysis. Not affiliated with or endorsed by NASCAR, Formula 1 or INDYCAR.
